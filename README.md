# Temple Architecture & Vastu Geometry Visualizer

An Angular standalone app for exploring temple layouts and Vastu geometry. The workspace includes an interactive 9×9 Vastu Purusha Mandala, site dimensions, north orientation, layer visibility, zone selection, zoom controls, and SVG plan export.

## Run locally

```bash
npm install
npm start
```

Open the local address printed by Angular CLI. Create a production bundle with `npm run build`.
